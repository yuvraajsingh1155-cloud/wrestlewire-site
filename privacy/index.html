Privacy Policy

A clear explanation of how this independent website handles data.

What we directly collect

As currently configured, WrestleWire has no visitor accounts, payment forms, advertising pixels, newsletters or visitor-submitted personal-data forms. The website itself does not ask visitors to provide names, email addresses or financial details.

Hosting and infrastructure

WrestleWire is delivered through Cloudflare Workers. As a network and hosting provider, Cloudflare may process connection information, including IP address, request metadata and security logs, under its own terms and privacy policies. GitHub stores the site's public source code.

Website measurement

We use the free Cloudflare Web Analytics beacon to measure page views and website performance. Cloudflare states that this product uses no visitor-tracking cookies. It can process technical performance and request information under its own privacy documentation. If Google Analytics is activated in the future, this policy will be updated to identify it and an appropriate consent mechanism will be provided before optional tracking is enabled where required.

Links to other websites

News stories and wrestler pages may link to WWE, AEW, YouTube, Wikimedia Commons or other websites. Those websites have their own privacy and cookie policies, and WrestleWire cannot control their practices.

Advertising

There is no active AdSense advertising account or ad code on the website at the time of this policy's initial publication. Before ads are activated, this notice and any required consent tools will be updated to describe advertising data processing.

Contact and privacy questions

For website content or privacy concerns, use the contact page or GitHub project issue tracker. GitHub issues are public; do not share passwords, private contact details, medical information or personal identifiers in a public issue.

Updates

This notice may change if the site's features change. Check the site's policy page for the current disclosure.
