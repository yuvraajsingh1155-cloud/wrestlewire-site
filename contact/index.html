General feedback

WrestleWire currently uses the public GitHub project issue tracker for page corrections and general website feedback. You can open an issue to report broken links, outdated wrestler information or inaccurate sourcing.

How to report a correction

Please include the WrestleWire article URL, the statement to correct and a link to a reliable supporting source. The editorial team can then review and adjust the page accordingly.

Privacy notice

GitHub issues are public. Do not post private identifying information, personal medical details, passwords, API keys, bank details or other sensitive information. The site does not currently offer a private message inbox or staffed customer service line.

Affiliations

WrestleWire is an independent project and is not an official communication channel for WWE, AEW or the wrestlers covered.
